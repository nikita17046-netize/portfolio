# Premium Developer Portfolio

A high-performance, modern, and fully responsive developer portfolio built with React, Vite, Tailwind CSS, and Framer Motion.

## ✨ Features

- 🚀 **Advanced UI/UX**: Glassmorphism, smooth scrolling, and premium micro-animations.
- 🌓 **Dark Mode**: Seamless theme switching with system preference detection and localStorage persistence.
- 🎨 **Hero Section**: Animated typing effect, gradient backgrounds, and social integrations.
- 📂 **Project Showcase**: Category filtering, detailed modal views (Problem/Solution/Learnings), and hover effects.
- 📊 **Skills Tracking**: Animated proficiency bars with tech-stack icons.
- 📝 **Dynamic Blog**: JSON-driven blog cards with modal reading view.
- 📩 **Contact Form**: Built-in validation, loading states, and success notifications.
- 🖱️ **Premium Touches**: Custom cursor, scroll progress bar, and "Back to Top" button.
- 🔍 **SEO Optimized**: Meta tags and Open Graph support for social sharing.

## 🛠️ Tech Stack

- **Framework**: React 18
- **Build Tool**: Vite
- **Styling**: Tailwind CSS
- **Animations**: Framer Motion
- **Icons**: React Icons (Fa, Si)
- **Deployment**: Optimized for Vercel/Netlify

## 🚀 Getting Started

1. **Clone the repository**
   ```bash
   git clone <repo-url>
   ```

2. **Install dependencies**
   ```bash
   npm install
   ```

3. **Run development server**
   ```bash
   npm run dev
   ```

4. **Build for production**
   ```bash
   npm run build
   ```

## 📄 Data Management

All content (projects, skills, blogs) is managed through `src/utils/data.json`, making it extremely easy to update without touching the code.
